# Nexora LinkedIn post — publish after confirmed Devpost submission

I built Nexora to explore a practical question: how can a study assistant help you decide what to learn next?

Nexora connects four parts of the learning process: focused lessons, active-recall practice, saved progress, and a plan that changes after each answer.

In the working demo, completing a Booth algorithm question updates the practice score and makes Cache mapping the next priority. Change the available study time, and the plan adjusts with it. Memory and Insights make those changes visible.

Built with React, TypeScript, Vite, and a Python/FastAPI backend, with a reusable open-source MCP toolkit. This is an Alexa+ web simulation; the hosted demo uses deterministic scoring and browser-local state. Bedrock and AgentCore integration code is included, with live cloud verification still ahead.

My biggest takeaway: keeping learning state explicit and testable makes an adaptive interface easier to explain and improve.

Submitted to the Build, Ship, Shape: Amazon Developer Hackathon.
